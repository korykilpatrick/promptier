Reuse Great Prompts, Skip the Copy-Paste.

`promptier` helps you manage, reuse, and share your favorite prompts efficiently, eliminating the need for constant copy-pasting and searching through scattered notes.

## Features

*   **Prompt Library:** Store and organize your prompts in a central library.
*   **Easy Retrieval:** Quickly search and find the prompts you need.
*   **Placeholders & Templating:** Use variables and templates for dynamic prompt generation.
*   **File Mapping:** Map files from your filesystem to variables for dynamic content injection.


**From source:**

```bash
git clone https://github.com/your-username/promptier.git # Replace with your repo URL
cd promptier/extension && pnpm install
cd promptier/server && npm install
```
